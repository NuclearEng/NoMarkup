## 2. What this product is

Two-sided marketplace (zone **`no-markup.com`**):

- **Services** — reverse auction: post jobs → sealed bids (price descends) → award → contract → escrow → complete → review. Instant match (flag/geo/trust) as emergency path.
- **Goods** — forward auction: list → bid/BIN → order → mutual pickup escrow → release/dispute. Local pickup posture; promote (paid boost) available.

Stack (locked): Next.js 15 web · Go gateway + services · Rust engines (bidding, fraud, trust, imaging, underwriting, pricing) · Postgres + PostGIS · Redis · Meilisearch · Stripe · native **iOS SwiftUI** (`ios/NoMarkup`).

Admin FR-13 is **web-only** by design (`/admin/*`).

- **`background_checks`:** default **false**; POST fails closed without `CHECKR_API_KEY`.
- **StoreKit:** `StoreKitEnabled` / `NOMARKUP_STOREKIT_ENABLED` default **false** (free-tier binary).
