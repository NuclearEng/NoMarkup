Source comment:

```5:6:ios/NoMarkup/Core/NoMarkupIcon.swift
/// so the home tile, login header, and homescreen icon stay pixel-aligned.
```

### Display use

`NoMarkupIcon` defaults to **120 pt** frame (also used at 72 / 160 in previews) — SwiftUI scales the raster down:

```11:20:ios/NoMarkup/Core/NoMarkupIcon.swift
    var size: CGFloat = 120
    // ...
        Image("BrandAppIcon")
            .resizable()
            .interpolation(.high)
            .scaledToFit()
            .frame(width: size, height: size)
```

### Perf note (not a hard fail of catalog p95)

Shipping a **1024×1024** 1x imageset slot means UIKit/SwiftUI may decode a large bitmap for a small chrome tile. Acceptable for v1 brand fidelity; **P2** optimization: provide true 1x/2x/3x sizes (~120/240/360 px for a 120 pt tile) to cut decode + memory.

**Local byte-size command (not run in agent sandbox):**

```bash
ls -la ios/NoMarkup/Assets.xcassets/BrandAppIcon.imageset/
sips -g pixelWidth -g pixelHeight \
  ios/NoMarkup/Assets.xcassets/BrandAppIcon.imageset/BrandAppIcon*.png
```

## 3. List screens use pagination

### API client (page + page_size, cap 100)

```269:281:ios/NoMarkup/Core/APIClient.swift
    /// GET `/api/v1/jobs?page=&page_size=&q=`
    func fetchJobs(page: Int = 1, pageSize: Int = 20, q: String? = nil) async throws -> JobsResponse {
        var items = [
            URLQueryItem(name: "page", value: String(max(1, page))),
            URLQueryItem(name: "page_size", value: String(min(max(1, pageSize), 100))),
        ]
        // ...
        return try await getJSON(pathComponents: ["api", "v1", "jobs"], query: items)
    }
```

Listings fetch uses the same `page` / `page_size` pattern (`APIClient.swift:219–228` region).

### Jobs browse / mine — pageSize 40 + load-more

