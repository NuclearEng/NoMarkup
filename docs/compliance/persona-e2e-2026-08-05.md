## 4. Fix applied during e2e (admin console tabs)

**Symptom:** `test05AdminSessionWalk` failed after opening Admin console:

```
Failed to determine hittability of "Users" Button:
Activation point invalid and no suggested hit points based on element frame
```

**Root cause:** Admin section tabs are a **horizontal** capsule `ScrollView`. After tapping “Disputes”, “Users” exists in the hierarchy but is off-screen; XCTest’s `isHittable` **throws** instead of returning false.

**Fix:**

1. **App** — stable a11y ids on each tab button:  
   `admin.console.tab.<slug>` in `ParitySurfacesView.swift` (`AdminConsoleView`).
2. **UITest** — geometric `isOnScreen` + coordinate `safeTap` + horizontal `tapAdminConsoleTab` (swipe left/right on `admin.console.tabs`) in `ScreenshotWalkUITests.swift`. Avoids raw `isHittable` on the strip.
