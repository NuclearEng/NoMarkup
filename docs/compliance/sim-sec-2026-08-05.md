## 1. ATS / Info.plist (shipping)

**PASS**

- App `ios/NoMarkup/Info.plist`: no `NSAppTransportSecurity` dictionary; no `NSAllowsArbitraryLoads`; no `NSAllowsLocalNetworking`.
- Widget `ios/NoMarkupWidget/Info.plist`: same (no ATS exception keys).
- Committed `APIBaseURL` is **empty** (production HTTPS via `AppConfig` default). Comment explicitly forbids committing cleartext LAN URLs.
- `GENERATE_INFOPLIST_FILE = NO` for the app target — shipping plist is the committed file (no generated ATS backdoor).
- Archive gate: `scripts/ios-archive-lint.sh` fails if `NSAppTransportSecurity` reappears or if `APIBaseURL` is non-empty non-`https`.

Default ATS applies → HTTPS-only for network loads in App Store / Archive / Release.

## 2. AppConfig Release cleartext rejection

**PASS**

Evidence in `ios/NoMarkup/Core/AppConfig.swift`:

| Layer | Behavior |
|-------|----------|
| `allowCleartext` | `#if DEBUG` → `true`; else → `false` |
| `resolveAPIBaseURL` | Skips non-`https` env/plist when `allowCleartext == false` |
| Release belt | `#if !DEBUG`: if resolved URL is not HTTPS → log once + force `productionAPIBaseURL` |
| Production default | `https://api.no-markup.com` |
| Plist | `APIBaseURL` empty |

Unit coverage: `ios/NoMarkupTests/AppConfigTests.swift` — `testReleaseRejectsCleartextEnvAndPlist`, `testIsHTTPSAPIBaseRejectsHTTP`, production fallback.

**Debug dogfood (intentional, not shipping):**

- Shared scheme `NoMarkup.xcscheme` **LaunchAction** (Debug) sets `NOMARKUP_API_BASE_URL=http://192.168.1.101:8081`.
- **ProfileAction** `shouldUseLaunchSchemeArgsEnv=NO`; **ArchiveAction** is Release — scheme env does not ship.
- DEBUG + Simulator default: `http://127.0.0.1:8081` when env empty.
- WebSocket helpers map `https`→`wss` / `http`→`ws` from the resolved API base; Release path is HTTPS → WSS only.

Without ATS exceptions, physical-device Debug cleartext may still be blocked by OS ATS (prefer HTTPS staging/tunnel). That is fail-closed relative to shipping, not a Release regression.
